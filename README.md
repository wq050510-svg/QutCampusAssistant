# 青理校园助手 (QUT Campus Assistant)
> 专为青岛理工大学学生定制的现代化校园综合服务 App（支持 Android 8.0+ 及现代 Material You）

---

## 项目特色与核心功能清单

### 1. 教务极速直连与自动抓包（纯原生，无需跳转网页）
- **原生 RSA/ECB/PKCS1Padding 密码加密**：直接调用教务公钥接口，极速完成登录并自动抓取全部数据。
- **学籍信息自动识别**：提取学生姓名、学号、班级、学院等信息。
- **离线秒开机制**：首次同步后数据由 Jetpack Room 本地数据库持久化缓存，无网状态秒开课表。

### 2. 双视图智能课表
- **周课表网格视图**：
  - 支持 1~20 周横向快速切周；
  - **单双周教室智能切换**：自动适配单双周更换教室的情况，高亮当前周真正要去的教室，杜绝跑错楼层；
  - **多小节连上合并**：1-2节、3-4节、5-6节、9-10节自动合并为大卡片展示；
  - **实践课不遗漏**：自动将常规教学楼课程与实践/短学期课程全部合并解析展示；
  - **同课同色柔和马卡龙**：按课程名称哈希分配护眼莫兰迪色系；
  - 点击卡片弹出精致 BottomSheet，详细显示教室、教师、学分、周次范围及重修标识。
- **每日时间轴视图**：
  - 聚焦当天所有课程安排，清晰展示上课起止倒计时。

### 3. 手机系统日历智能联动（带闹钟提醒）
- **独立日历本隔离**：在系统日历中注册独立的 `青岛理工大学课表` 账户，一键同步更新或一键抹除清空，绝不污染个人私人日程；
- **精准映射黄岛校区教学作息**：自动将全学期各周课程展开为公历事件，精确计算到分钟；
- **系统级准时提醒**：支持设置上课前 10~30 分钟通过系统日历弹出横幅或全屏强提醒。

### 4. 桌面小组件（极简透明插画样式）
- **全透明悬浮质感**：背景全透明，文字自带轻微阴影，完美融入各种壁纸；
- **智能状态呈现**：
  - **无课时**：呈现精美手绘文具插图（笔记本、铅笔、眼镜）与 `今天没有课哦`；
  - **有课时**：展示今日教学楼与教室流、上下课时间段与下节课倒计时；
- **顶栏交互**：左上角动态显示日期与学期周次，右侧配备 `明日 →` 快速预览按钮。

### 5. 考试安排与座位号直通车
- 抓取期末/补考安排，不仅清晰展示科目和起止时间，还提供精准考场地点和**座位号**。

### 6. 历年成绩单与学业画像
- 成绩栏目展示历年考试成绩（重修后成绩自动替换更新）；
- 学业画像单独呈现学院官方审定的平均学分绩点（GPA）、修读总学分及未通过课程预警。

### 7. 深色模式（AMOLED 纯黑优化）
- 深度适配系统深色主题，护眼且省电。

 │    │         ├── layout/                 # 桌面小组件布局 widget_schedule_layout.xml

## 如何在手机上运行安装
 
1. 打开 **Android Studio**；
2. 选择 **Open**，直接打开目录：`C:\Users\18161\.gemini\antigravity\scratch\QutCampusAssistant`；
3. 将 Android 手机通过 USB 数据线连接电脑，在开发者选项中开启【USB 调试】；
4. 点击 Android Studio 顶部的绿色 **Run (运行)** 按钮，即可将 App 直接安装到手机上！
5. 在手机桌面上长按或双指捏合 -> 点击【小部件/微件】-> 找到【青理校园助手】-> 添加【今日课表(极简透明)】即可在桌面上体验！
